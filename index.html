Dokumentasi arsitektur server, alur dispatch, dan panduan Rust.

Arsitektur use case

Use case Dispatch Operator menerima permintaan melalui adapter/controller inbound, menjalankan aturan bisnis di service, lalu memakai port outbound untuk mengakses data.

View (DispatcherPage)
  → Tauri Controller (adapter inbound)
  → ApiClient / HTTP
  → Axum Adapter → ServiceTrait (port inbound)
  → Service / Use Case
  → RepositoryTrait (port outbound)
  → Repository (adapter outbound) → Database

Komponen diagram

  • Views: halaman frontend seperti DispatcherPage dan CourierPage.
  • Controller: controller desktop menerima perintah UI dan meneruskan request ke API.
  • Inbound port: ServiceTrait mendefinisikan kontrak use case.
  • Outbound port: RepositoryTrait mendefinisikan operasi data yang dibutuhkan use case.
  • Entity: record data seperti Operator dan OrderItem; entity tidak perlu memiliki method bisnis.
  • Data access: repository mengimplementasikan seluruh method data access dan berkomunikasi dengan database.

DTO adalah bentuk request/response lintas batas layer; entity merepresentasikan data persistence. Adapter menerjemahkan protokol dan model yang digunakan tiap batas.

Alur dispatch

  1. View memilih courier dan order item, lalu memanggil command Tauri.
  2. Controller memvalidasi ID dan ApiClient mengirim HTTP POST.
  3. Axum mengurai DTO request dan memanggil ServiceTrait::dispatch_operator().
  4. Service mengambil operator dan order item melalui repository, kemudian memeriksa availability, role, dan status.
  5. Repository menjalankan transaksi untuk memperbarui operator serta order item, lalu commit.
  6. Hasil dikembalikan ke view agar UI dapat menampilkan status dan memperbarui data.
DispatcherPage → DispatcherController::dispatch_operator()
→ ApiClient::dispatch_operator() → Axum handler
→ ServiceTrait::dispatch_operator() → Service::dispatch_operator()
→ RepositoryTrait::find_operator() + get_order_item()
→ RepositoryTrait::dispatch_operator() → transaction / commit
→ response kembali ke DispatcherPage

  → [valid: update operator + order item dalam transaksi]
